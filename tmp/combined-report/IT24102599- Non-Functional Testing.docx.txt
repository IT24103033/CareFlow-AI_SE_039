Non-Functional Testing Scope
The individual testing contribution focused on the non-functional aspects of the CareFlow AI backend API. Testing was carried out on the locally running system using k6, OWASP ZAP, and manual API checks. The main areas selected were performance, security, and reliability.
Performance Testing
A k6 load test was carried out on the authenticated /api/appointments endpoint. The test gradually increased the number of virtual users up to 5 while monitoring response times and request failures. This helped check how the API performed under a small amount of concurrent load.
Security Testing
Security checks covered both automated scanning and manual API testing. OWASP ZAP was used to scan the API for common security issues. Additional checks were done for unauthenticated access and role-based authorization, including verifying that a Doctor could not access an Admin-only endpoint.
Reliability Testing
A repeated request test was carried out using k6 on the authenticated /api/appointments endpoint. The same request was sent multiple times to check whether the API remained available and continued to return successful responses during normal repeated use.
